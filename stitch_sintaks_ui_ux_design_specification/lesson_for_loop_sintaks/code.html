# For Loop

Dalam Python, for loop digunakan untuk melakukan iterasi (pengulangan) pada urutan (seperti list, tuple, dictionary, set, atau string). Ini memungkinkan kita untuk mengeksekusi sekumpulan pernyataan, sekali untuk setiap item dalam list, tuple, set dll.

code Python 
for i in range(5):
    print(i)

Output

0
1
2
3
4
info
Key Point

Fungsi range(5) menghasilkan 5 angka berurutan mulai dari 0 hingga 4 (berhenti sebelum 5).
